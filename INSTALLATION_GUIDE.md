## 🔧 Installation Steps

### Step 1: Open Chrome Extensions Page
1. **Open Google Chrome**
2. **Navigate to extensions page** using one of these methods:
   - Type `chrome://extensions/` in the address bar and press Enter
   - Click **Menu (⋮)** → **Extensions** → **Manage Extensions**
   - Right-click any extension icon → **Manage Extensions**

### Step 2: Enable Developer Mode
1. **Look for "Developer mode"** toggle in the top-right corner of the extensions page
2. **Click to toggle ON** (switch should turn blue/enabled)
3. **New buttons appear**: "Load unpacked", "Pack extension", "Update"

### Step 3: Load Your Extension
1. **Click "Load unpacked" button**
2. **File browser window opens**
3. **Navigate to**: `/Users/frankliu/Library/CloudStorage/Box-Box/Work/clickable`
4. **Select the entire `clickable` folder** (not individual files)
5. **Click "Select Folder"** (macOS) or "Open" (Windows)

### Step 4: Verify Installation
The extension should now appear in your extensions list with:
- ✅ **Name**: "Clickable Links"
- ✅ **Version**: "2.9"
- ✅ **Description**: "Turns unclickable urls & email addresses into clickable ones..."
- ✅ **Status**: Enabled (toggle should be ON)
- ✅ **Unique Extension ID**: Automatically generated by Chrome

## 🧪 Testing Your Extension

### Basic Functionality Test
1. **Visit any webpage** (avoid Google, Bing, Twitter - they're excluded)
2. **Create test content** by pasting this in a text editor or document:
   ```
   Test URLs:
   - Complete: https://example.com/page?param=value
   - With commas: https://site.com/search?tags=red,blue,green
   - Domain only: example.org
   - Email: contact@example.com
   - IP address: 192.168.1.1
   - In sentence: Visit example.com, then go to site.org
   ```
3. **Copy and paste** into a webpage (like Gmail draft, Google Docs, etc.)
4. **Verify results**:
   - URLs become clickable blue links
   - Comma-separated parameters included in links
   - Sentence punctuation commas excluded from links
   - Email addresses become `mailto:` links

### Advanced Testing
1. **Test your specific URL**:
   ```
   https://funbench.siri.apple.com/compare/scenario/call_mcdonalds_local_contact_vs_business_displayForward?runs=gepa_datagen_multi_scenario_20251215_221046,gepa_datagen_multi_scenario_20251215_221734
   ```
   - Should become fully clickable including comma-separated values

2. **Test sentence punctuation**:
   ```
   Visit example.com, then check out test.org for more information.
   ```
   - Should create separate links for `example.com` and `test.org`
   - Commas should NOT be included in the links

### Options Testing
1. **Access extension options**:
   - Right-click extension icon → "Options" (if icon pinned)
   - OR go to `chrome://extensions/` → find "Clickable Links" → "Details" → "Extension options"
2. **Test "Open links in new tab" setting**:
   - Toggle checkbox ON/OFF
   - Click "Save"
   - Test links open in same tab vs new tab

## 🛠️ Developer Tools & Debugging

### Chrome DevTools Console
1. **Right-click any webpage** → "Inspect" → "Console" tab
2. **View extension errors** and `console.log()` output
3. **Test regex patterns** manually:
   ```javascript
   // Test comma handling
   var text = "Visit https://site.com/page?runs=a,b,c, then go to example.com";
   var pattern = /((https?|ftp):\/\/[^\s\/$.?#\(\)].(?:[^\s\(\),]|,(?!\s))*)/gi;
   console.log(text.replace(pattern, '<LINK>$1</LINK>'));
   ```

### Extension Error Checking
1. **Go to** `chrome://extensions/`
2. **Look for error messages** in red under your extension
3. **Click "Errors" button** (if present) to see details
4. **Common issues**:
   - Syntax errors in JavaScript
   - Invalid JSON in manifest.json
   - Missing files referenced in manifest

### Storage Inspection
Check extension settings in DevTools:
```javascript
// Run in any webpage console
chrome.storage.sync.get(null, (data) => console.log('Extension settings:', data));
```

## 🔍 Troubleshooting

### Extension Won't Load
**Problem**: "Load unpacked" fails or extension doesn't appear

**Solutions**:
- ✅ Verify `manifest.json` exists in root directory
- ✅ Check `manifest.json` syntax (use JSON validator)
- ✅ Ensure all files referenced in manifest exist
- ✅ Check file permissions (readable by Chrome)
- ✅ Try loading from a different directory path

### Changes Not Taking Effect
**Problem**: Code modifications don't work on webpages

**Solutions**:
- 🔄 **Always reload extension** after changes
- 🔄 **Refresh test webpage** after reloading extension
- 🧹 **Clear browser cache**: Settings → Privacy → Clear browsing data
- 🔍 **Check for JavaScript errors** in console
- 🎯 **Test on different websites** (avoid excluded sites)

### Extension Disabled or Broken
**Problem**: Extension shows as disabled or has errors

**Solutions**:
- 🔧 **Check Extensions page** for error messages
- 📝 **Validate JavaScript syntax** (use online JS validator)
- 📋 **Verify manifest.json format** (use JSON validator)
- 🔄 **Remove and reload** extension if corrupted
- 📁 **Check file encoding** (should be UTF-8)

### Links Not Appearing
**Problem**: URLs on page don't become clickable

**Solutions**:
- 🚫 **Check if site is excluded** (Google, Bing, Twitter are excluded)
- 🔍 **Inspect page elements** - links might be in excluded tags (`<script>`, `<code>`, etc.)
- 🧪 **Test patterns** in console with sample text
- 📱 **Verify content script injection** in DevTools Sources tab
- ⏱️ **Wait for page load** - extension runs after DOM ready

### Pattern Testing Issues
**Problem**: URLs don't match expected patterns

**Test patterns individually**:
```javascript
// Email pattern
/([A-Z0-9._%+-]+@[A-Z0-9.-]+\.[A-Z]{2,4})/gi.test('user@example.com')

// Complete URL pattern
/((https?|ftp):\/\/[^\s\/$.?#\(\)].(?:[^\s\(\),]|,(?!\s))*)/gi.test('https://site.com/page?a=1,2')

// Domain pattern
/(([^\s\/$.?#\(\)](?:[^\s,]|,(?!\s))*)\.(com|net|org)((?:[^\s\(\),]|,(?!\s))*))/gi.test('example.com/path')
```

## 📦 Optional: Packaging Extension

### When to Package
You only need to create a `.crx` package if you want to:
- **Share with others** who can't load unpacked extensions
- **Submit to Chrome Web Store**
- **Distribute outside of development**

### Packaging Steps
1. **Go to** `chrome://extensions/`
2. **Click "Pack extension" button**
3. **Extension root directory**: Browse to `/Users/frankliu/Library/CloudStorage/Box-Box/Work/clickable`
4. **Private key file**: Leave blank for first time (Chrome generates one)
5. **Click "Pack Extension"**
6. **Result**: Creates `clickable.crx` and `clickable.pem` files

### Installing Packaged Extension
1. **Drag and drop** the `.crx` file onto `chrome://extensions/`
2. **Click "Add extension"** in the confirmation dialog
3. **Note**: Packaged extensions can't be reloaded - you need to repackage after changes
